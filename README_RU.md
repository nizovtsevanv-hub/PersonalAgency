# FLUFFY SOUND LAB — FSL-P01 «Ship or Sheep?»

Пилотный обучающий веб-модуль произношения для контраста британских гласных
**/ɪ/ ↔ /iː/** (ship — sheep). Работает полностью в браузере: без бэкенда,
без регистрации, без API-ключей и без отправки данных куда-либо.

## Что это

- Один фонетический «движок» и три маршрута: **Kids Lab** (дети 5–7),
  **Grown-ups Lab** (взрослые), **Together Mode** (ребёнок + взрослый).
- Путь обучения: `Hear it → See it → Move it → Say it → Read it → Use it`
  (11 экранов: выбор режима, разминка-диагностика, визуальный крючок,
  лаборатория слуха, лаборатория рта, значки IPA, мост правописания,
  запись голоса, перенос в речь, «звуковой босс», паспорт звуков).
- Каждая карточка слова строго в формате: **английское слово → британская
  транскрипция IPA → русский перевод** (например: `ship` · `/ʃɪp/` · `корабль`).
- Маскот Флаффи — функциональный «тренер произношения» с состояниями
  (слушает, говорит, записывает, поддерживает, /ɪ/-импульс, /iː/-след, золото).

## Как запустить

Нужен Node.js 20+.

```bash
npm install        # установить зависимости
npm run dev        # локальный дев-сервер (адрес появится в терминале)
npm run build      # производственная сборка в папку dist/
npm run preview    # локальный просмотр производственной сборки
npm run lint       # проверка линтером (oxlint)
```

Откройте адрес из терминала (обычно `http://localhost:5173`) в браузере.
Основное целевое устройство — iPhone Safari; также поддерживаются Android,
планшеты и десктоп.

## Как выложить на GitHub Pages

Сборка использует `base: "./"` (относительные пути), поэтому она работает на
GitHub Pages без привязки к имени репозитория.

Самый простой способ — GitHub Actions:

1. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
2. Добавьте workflow `.github/workflows/deploy.yml`:

```yaml
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  build-deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with: { path: dist }
      - id: deployment
        uses: actions/deploy-pages@v4
```

3. После пуша в `main` сайт появится по адресу
   `https://<пользователь>.github.io/<репозиторий>/`.

Альтернатива без Actions: `npm run build` и опубликовать содержимое `dist/`
в ветку `gh-pages` (например, пакетом `gh-pages`).

## Как добавить следующий звуковой блок (Sound Block)

1. Создайте файл содержимого по образцу `src/content/FSL-P01.json`
   (слова, IPA, русские значения, предложения, диалог).
2. Типы уже описаны в `src/types/content.ts` — новый JSON должен им
   соответствовать.
3. Экраны (`src/screens/*`) написаны поверх содержимого: большинство из них
   можно переиспользовать, поменяв источник данных в `src/content/index.ts`.
4. В `src/components/SoundPassport.tsx` переведите соответствующий узел из
   `Coming next` в активное состояние.
5. Ключ хранения прогресса (`fluffy-sound-lab-p01` в
   `src/services/progressService.ts`) для нового модуля должен быть другим
   (например `fluffy-sound-lab-p02`).

## Как заменить синтетический голос на живую британскую озвучку

Сейчас звук работает через `speechSynthesis` с предпочтением голоса `en-GB`.
Приложение **автоматически** переключится на файлы, как только они появятся:

1. Запишите диктора (см. список и требования в `AUDIO_REGISTER.md`).
2. Положите mp3-файлы в `public/audio/` со строгими именами вида
   `en-gb-f1-ship.mp3` (голос f1 — женский, m1 — мужской):
   `en-gb-f1-<ключ>.mp3` / `en-gb-m1-<ключ>.mp3`, где `<ключ>` — id слова
   (`ship`, `sheep`, `sit`, `seat`, `fill`, `feel`, `live`, `leave`, `bit`,
   `beat`) или id предложения (`kids-story`, `adult-key`, `together-key`).
3. Никакого кода менять не нужно: сервис `src/services/audioService.ts`
   сначала проверяет наличие локального файла и лишь потом использует TTS.
4. Обновите статусы в `AUDIO_REGISTER.md`.

Сайт полностью работает и без этих файлов.

## Микрофон и камера: приватность

- **Микрофон** используется только на экранах записи (Speak & Replay и финал
  «Sound Boss»). Запись живёт **в памяти страницы** (объектный URL) и
  удаляется при замене или закрытии. Она **не сохраняется** в localStorage и
  **не отправляется** ни на какой сервер.
- **Камера** используется только в необязательном «Режиме зеркала» (Mirror
  Mode) в Лаборатории рта. Изображение показывается локально, не
  записывается и не передаётся. Все дорожки камеры останавливаются при
  закрытии зеркала.
- Если доступ к микрофону или камере не дан — урок полностью проходим:
  включается маршрут «послушай и повтори вслух», а схема рта остаётся
  доступной.
- В localStorage (ключ `fluffy-sound-lab-p01`) хранится только прогресс:
  режим, текущий экран, результаты детерминированных заданий и настройки.
  Кнопка **Reset progress** (в настройках) удаляет всё с подтверждением.
